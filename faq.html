Even More About Me

I still don't know who you are. Care to explain?

Hi, I'm me. Welcome to my sanctum.

What's up with your old aliases?

I made the name 'LGameMaker13' back when I was a wee lad, and that name has somehow stuck with me all these years.
As much as I'd like to change it, I'm too creatively bankrupt to think of anything else.

When did you start making stuff online?

I "discovered" Scratch back in 2019, but I brushed it off for not being "real coding". A year later (during the pandemic), I revisited Scratch and found it to be quite the neat tool. Ever since then, I've been making games on there.
As for IGM, I started making a bunch of crappy, now-deleted clicker games back in 2019, until I lost interest and stopped. Then in 2022, I picked up coding in IGM again and started making actually decent stuff.

Where did your avatar come from?

That silly goober came from a now-deleted Scratch project. It was for an outro for all the animations I, admittedly, never made. Surprisingly, he's received some fan art before. He also canonically has a Creeper 2DS, just as I do.

How'd you learn to code?

Trial and error. It might take a long time to become "proficient", but it's worth the grind.

The Web Site

How did you make this place?

I use Neocities for hosting, GitHub for the repo, and VSCodium for coding.

Any external resources you use?

I also use W3Schools for HTML/JS tutorials, GIMP for image editing, and optiPNG for image compression

You're telling me you've NEVER used a layout builder?

Correct! I haven't used one because I thought it'd be more fun to make an entire website straight from scratch, especially considering my affiliation with CSS through Idle Game Maker. It actually ended up working out quite well.

What's with the version number? Shouldn't those just be for games?

Ever since I started making games back in 2019, I've always been obsessed with version numbers. Whether it's formatted X.Y or X.Y.Z, I'm all for it. (one-digit version numbers are no good, though.)

What's with the space between web and site?

I faintly remember making a typo during the early days of the site, which was an accidental space in the word 'website'. I thought it'd be funny to just roll with it, and it's stuck ever since.

Any other websites or HTML5 stuff you've made?

I mean, there's a now-defunct GitHub Pages version of this site. It was made on October 15, 2023, but my stupid ass deleted the repo shortly after v2.0 released.
